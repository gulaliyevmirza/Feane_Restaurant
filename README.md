Feane Restaurant Website
A comprehensive restaurant management system built with Django and Bootstrap.

Features
Menu Management: View and browse a variety of delicious food items, categorized for easy navigation.

Table Reservation: Book a table directly from the website.

Shopping Cart: Add items to your cart and manage your order.

Responsive Design: Fully responsive layout that looks great on all devices.

Technologies Used
Backend: Django

Frontend: Bootstrap, HTML, CSS, JavaScript

Installation
Clone the repository:

Bash
git clone <repository-url>
Navigate to the project directory:

Bash
cd Feane
Create and activate a virtual environment:

Bash
python -m venv .venv
source .venv/bin/activate
Install the required dependencies:

Bash
pip install -r requirements.txt
Apply migrations:

Bash
python manage.py migrate
Run the development server:

Bash
python manage.py run manage.py runserver
